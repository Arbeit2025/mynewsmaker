# マイ新聞メーカー（mynewsmaker）

メモや出来事を「新聞の一面」風レイアウトで表示するメーカーです。新聞（号）を作成し、題字（新聞名）・日付・複数の記事（見出し＋本文）を登録すると、明朝体の題字と段組み風の紙面で表示されます。単一ファイル Flask + SQLite で動きます。

着想元は、GitHub フォロワー ErBharatMalhotra さんの daily-prompt-public（自律生成の新聞サイト）です。メモや学習ログなどを新聞の一面風に眺める楽しさを、小さな手入力メーカーとして作り直しました。

## 機能

- **号の作成**：新聞名（題字）、日付（空欄なら当日）、記事を複数登録できます。記事欄は画面上で増やせます（1号につき最大20件）。
- **号の一覧**：発行した号を日付の新しい順に表示します。各号の記事数も出ます。
- **号の表示（紙面）**：大きな題字、日付と号数、段組み（2段・スマホでは1段）風のレイアウトで記事を表示します。先頭の記事は見出しが大きくなります。
- **号の削除**：一覧または表示ページから削除できます（記事ごと消えます）。

## バリデーション

- 新聞名（題字）が空の号は作れません。
- 見出しが空の記事は受け付けません（本文だけの記事があるとエラーになります）。見出しも本文も空の記事欄は無視されます。
- 記事が1件も無い号は作れません。
- 日付の形式が不正だとエラーになります。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

DB のパスは環境変数 `MYNEWSMAKER_DB` で変更できます（既定は app.py と同じ場所の `mynewsmaker.db`）。外部 API は使わず、ログイン機能もありません。

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- **無料プランでは SQLite のデータが再デプロイ等で消える場合があります。** 大事な号は表示ページを保存するなど、別途控えを取ってください。
- ログイン機能はありません。公開する場合は誰でも閲覧・作成・削除できる前提になります。
- 画像の掲載や、実際の新聞のような複雑な組版には対応していません（段組みは CSS の表現のみです）。
